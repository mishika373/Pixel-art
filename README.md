# Pixel Art Maker

A simple and interactive web-based Pixel Art Maker that allows users to create pixel artwork directly in the browser.

Start creating -https://pixel-art-nu-nine.vercel.app

 Features:
- Custom color picker
- Dynamic grid size
- Click-to-draw functionality
- Drag-to-draw functionality
- Eraser tool
- Clear grid option
- Download artwork as PNG
- Responsive and user-friendly interface

Technologies Used:
- HTML5
- CSS3
- JavaScript

How to Use:
1. Select your desired grid size.
2. Click Create Grid.
3. Choose a color from the color picker or palette.
4. Click or drag across the grid to create your artwork.
5. Use the Eraser to remove pixels.
6. Use Clear Grid to start over.
7. Click Download Drawing to save your artwork as a PNG image.
